⚡ eConversion Pipeline Map

sources → build → caches → tools → registry → delivery
An interactive lineage map of the eConversion knowledge assistant. Raw sources are turned by build scripts into local caches, which back the MCP tools the agent calls; a single registry exposes those tools to both delivery surfaces — the stdio MCP server and the Streamlit app. Click any node to draw its lineage: every box that feeds it and that it feeds lights up, connected by arrows.
