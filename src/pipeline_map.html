An interactive lineage map of the eConversion knowledge assistant. Six stages, left to right: raw sources are turned by build scripts into local caches, which back the MCP tools the agent calls; a single registry (the FastMCP server) exposes those tools to both the delivery surfaces — the stdio MCP server and the Streamlit app. Click any node to isolate what feeds it and what it feeds.
